# 🤖 AI智能伴侣

一个基于Streamlit和DeepSeek大语言模型的AI聊天伴侣应用，支持多会话管理、角色定制和对话持久化。

## ✨ 功能特性

- 🤖 **AI对话**: 基于DeepSeek大语言模型，提供流畅的AI对话体验
- 👤 **角色定制**: 自定义AI伴侣的昵称和性格描述
- 💬 **多会话管理**: 支持创建、加载、删除多个聊天会话
- 💾 **数据持久化**: 自动保存对话历史到本地JSON文件
- 🎨 **美观界面**: 基于Streamlit构建的现代化Web界面

## 🚀 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/your-username/ai-partner.git
cd ai-partner
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置环境变量

设置DeepSeek API密钥：

```bash
# Windows PowerShell
$env:DEEPSEEK_API_KEY="your-api-key-here"

# Linux/Mac
export DEEPSEEK_API_KEY="your-api-key-here"
```

### 4. 运行应用

```bash
streamlit run 09.ai_partner_5.py
```

应用将在浏览器中自动打开，默认地址为 `http://localhost:8501`

## 🛠️ 技术栈

- **Streamlit**: Web UI框架
- **OpenAI SDK**: 调用DeepSeek大语言模型API
- **JSON**: 会话数据持久化存储
- **Python 3.8+**: 运行环境

## 📝 代码架构

应用采用面向对象设计，所有功能封装在 `AIPartner` 类中，分为三大模块：

1. **初始化模块** - 设置页面配置、初始化会话状态、创建AI客户端
2. **会话管理模块** - 保存/加载/删除聊天会话，支持多会话切换
3. **UI渲染模块** - 渲染侧边栏控制面板和主聊天界面

## ⚙️ 配置说明

| 变量名 | 说明 | 必填 |
|--------|------|------|
| `DEEPSEEK_API_KEY` | DeepSeek API密钥 | 是 |

### 默认配置

- **默认昵称**: 小甜甜
- **默认性格**: 活泼开朗的东北姑娘
- **AI模型**: deepseek-flash

## 🎯 使用技巧

1. **自定义角色**: 在侧边栏修改昵称和性格描述，AI会立即以新身份回复
2. **多会话管理**: 点击"新建会话"创建新对话，历史会话可随时切换
3. **会话持久化**: 关闭浏览器后重新打开，历史会话依然保留
4. **流式输出**: AI回复会逐字显示，提供更好的交互体验
